# jmk-works.github.io

교안 노션 페이지로 이동하는 짧은 링크 모음입니다.

| 짧은 링크 | 교안 |
|---|---|
| https://jmk-works.github.io/sinokor | AI agent |
| https://jmk-works.github.io/dorocom | AI |

## 교안 추가하기

1. `sinokor` 폴더를 복사해 새 이름으로 만듭니다(예: `newclass/`). 폴더 이름이 짧은 링크 경로가 됩니다.
2. 새 폴더의 `index.html`에서 노션 주소 4곳과 `<title>`을 바꿉니다. 노션 주소 끝의 `?source=copy_link`는 빼도 됩니다.
3. 루트 `index.html` 목록과 위 표에 한 줄 추가합니다.
4. 커밋하고 푸시하면 1~2분 뒤 `https://jmk-works.github.io/newclass`가 동작합니다.
